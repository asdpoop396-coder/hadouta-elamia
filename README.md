# حدوتة إعلامية

موقع عربي للتعريف بتاريخ الإعلام المصري، من الصحافة والإذاعة إلى التلفزيون والإعلام الرقمي.

## تشغيل الموقع محليًا

افتح `index.html` في المتصفح. الموقع ثابت ولا يحتاج إلى تثبيت حزم أو تشغيل خادم.

## النشر على GitHub Pages

1. ارفع الملفات إلى الفرع `main` في المستودع العام.
2. من إعدادات المستودع افتح **Settings → Pages**.
3. ضمن **Build and deployment**، اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واضغط **Save**.
4. بعد اكتمال النشر، افتح رابط الموقع الظاهر في **Settings → Pages**. غالبًا سيكون `https://USERNAME.github.io/hadouta-elamia/`.

كل تحديث يُرفع إلى فرع `main` يُنشر تلقائيًا من المجلد الرئيسي.

## التعديل والمحتوى

- النصوص: `index.html`.
- التنسيق: `style.css`.
- التفاعلات وروابط التواصل والبريد: `script.js`.
- الصور: مجلد `images/`.
- دليل تعديل المحتوى والصور: `README.txt`.

لا تضع كلمات مرور أو مفاتيح وصول أو بيانات سرية في ملفات المستودع. الصور الحالية تعبيرية أو بدائل مؤقتة؛ راجع مصادرها وحقوق استخدامها قبل النشر العام.

محتويات المجلد
---------------
index.html   ← كل نصوص الموقع ومحتوى الحكايات
style.css    ← الألوان والخطوط والتنسيق
script.js    ← التفاعلات + روابط التواصل والبريد (في أول الملف)
favicon.svg  ← أيقونة الموقع في المتصفح
images/      ← كل الصور
README.txt   ← هذا الملف

لا يحتاج الموقع إلى أي تثبيت أو برامج. افتح index.html في المتصفح لمعاينته.
للتعديل استخدم أي محرر نصوص (مثل Visual Studio Code أو Notepad++)،
واحفظ الملفات بترميز UTF-8 حتى تظهر الحروف العربية بشكل صحيح.


---------------------------------------------------------
١) استبدال الصور
---------------------------------------------------------
أسهل طريقة: ضع صورتك الجديدة داخل مجلد images بنفس اسم الصورة القديمة
تمامًا (مثلًا person-02.jpg) واحذف القديمة. لا حاجة لتعديل أي كود.

قائمة الصور الحالية:
  hero-maspero.jpg      صورة الواجهة الرئيسية
  researcher-nesma.jpg  صورة الباحثة نسمة عودة (حاليًا إطار بديل)
  story-press.jpg       حكاية الصحافة
  story-radio.jpg       حكاية الإذاعة
  story-tv.jpg          حكاية التلفزيون
  media-ai.jpg          من الميكروفون إلى الذكاء الاصطناعي
  person-01.jpg         صلاح زكي        (حاليًا إطار بديل)
  person-02.jpg         جلال معوض       (حاليًا إطار بديل)
  person-03.jpg         أماني ناشد      (حاليًا إطار بديل)
  person-04.jpg         ليلى رستم       (حاليًا إطار بديل)
  women-pioneers.jpg    الصورة الكبيرة في قسم رائدات ماسبيرو
  pioneer-01..04.jpg    صور رائدات ماسبيرو (حاليًا إطارات بديلة)
  gallery-01..06.jpg    صور معرض الصور

مهم:
- جميع الصور الحالية صور تعبيرية أو إطارات بديلة، وليست صورًا أرشيفية حقيقية.
  استبدلها بصور أرشيفية موثقة مع ذكر مصدرها عند الإمكان.
- إذا حذفت صورة ولم تضع بديلًا، سيظهر مكانها إطار أنيق مكتوب عليه
  «صورة تُضاف قريبًا» بدلًا من علامة الصورة المكسورة.
- يُفضل ضغط الصور قبل رفعها (مثلًا عبر موقع squoosh.app المجاني)
  بحيث لا تتجاوز الصورة الواحدة 300 كيلوبايت تقريبًا.
- عند تغيير صورة عدّل أيضًا وصفها في الخاصية alt داخل index.html.


---------------------------------------------------------
٢) تعديل النصوص العربية
---------------------------------------------------------
كل النصوص موجودة في index.html، وكل قسم يبدأ بتعليق واضح مثل:
  <!-- ========== عن المنصة ========== -->
ابحث (Ctrl+F) عن الجملة التي تريد تغييرها واكتب النص الجديد مكانها،
مع الحفاظ على الوسوم المحيطة بها مثل <p> و </p>.

النصوص الكاملة للحكايات والسير موجودة في آخر index.html داخل وسوم <template>.

عنوان الموقع ووصفه في محركات البحث: أول index.html داخل <title>
و <meta name="description">.


---------------------------------------------------------
٣) تحديث روابط التواصل الاجتماعي والبريد الإلكتروني
---------------------------------------------------------
افتح script.js، وفي أوله ستجد:

  const SITE_CONFIG = {
    email: "",
    social: {
      facebook: "",
      instagram: "",
      tiktok: "",
      youtube: ""
    }
  };

ضع الرابط الكامل بين علامتي التنصيص، مثال:
  facebook: "https://www.facebook.com/اسم-الصفحة",
  email: "name@gmail.com",

يتحدث الرابط تلقائيًا في كل الأماكن (قسم تابعنا، التواصل، الفوتر).
الحساب الذي يُترك فارغًا يظهر بعلامة «قريبًا» ولا يفتح رابطًا وهميًا.


---------------------------------------------------------
٤) إضافة حكاية تاريخية جديدة
---------------------------------------------------------
الخطوة أ — بطاقة الحكاية:
في قسم «حكايات الإعلام» انسخ أي كتلة تبدأ بـ
  <article class="story-card reveal">
وتنتهي بـ </article>، والصقها بعدها، ثم غيّر:
  - الصورة (src) ووصفها (alt)
  - التصنيف داخل <span class="story-cat">
  - العنوان داخل <h3> والوصف داخل <p>
  - قيمة data-story في زر «اقرأ المزيد» إلى اسم جديد، مثل story-cinema

الخطوة ب — النص الكامل:
في آخر index.html انسخ أي <template> والصقه، ثم غيّر:
  id="story-cinema"            (نفس قيمة data-story بالضبط)
  data-title="عنوان الحكاية"
  data-cat="التصنيف"
  data-image="images/story-cinema.jpg"
واكتب النص الكامل بين <template ...> و </template>.

الخطوة ج — ضع الصورة الجديدة في مجلد images.


---------------------------------------------------------
٥) إضافة شخصية إعلامية جديدة
---------------------------------------------------------
في قسم «رموز الإعلام» انسخ كتلة
  <article class="person-card reveal"> ... </article>
وغيّر الصورة (مثلًا images/person-05.jpg) والاسم والنبذة والمجال،
وغيّر data-story إلى person-05.
ثم أضف <template id="person-05" ...> في آخر الملف بالسيرة الكاملة.

لإضافة رائدة في قسم «رائدات ماسبيرو» انسخ كتلة <li class="pioneer reveal">
بنفس الطريقة (pioneer-05).

لإضافة صورة للمعرض انسخ كتلة <figure class="gallery-item reveal">
وغيّر الصورة والتعليق؛ يعمل عارض الصور والتنقل بينها تلقائيًا.

تذكير: لا تُضف تواريخ أو مناصب أو إنجازات إلا بعد التحقق منها من مصادر موثوقة.


---------------------------------------------------------
٦) النشر المجاني عبر Netlify Drop
---------------------------------------------------------
١. افتح الموقع: https://app.netlify.com/drop
٢. سجّل الدخول أو أنشئ حسابًا مجانيًا (لحفظ الموقع بشكل دائم).
٣. اسحب المجلد بالكامل (الذي يحتوي index.html ومجلد images) وأفلته
   في المساحة المخصصة على الصفحة.
٤. انتظر ثوانٍ، وسيظهر رابط موقعك المنشور.
٥. من إعدادات الموقع: Site configuration ← Change site name
   يمكنك اختيار اسم مثل: hadouta-elamia.netlify.app
٦. لتحديث الموقع لاحقًا: من صفحة الموقع على Netlify افتح Deploys
   واسحب المجلد المعدّل مرة أخرى.

تفعيل استقبال الرسائل عبر Netlify Forms (اختياري ومجاني):
حاليًا يفتح نموذج التواصل برنامج البريد لدى الزائر (بعد إضافة بريدك في script.js).
لاستقبال الرسائل مباشرة في لوحة Netlify:
  أ. في index.html غيّر سطر النموذج إلى:
     <form class="contact-form reveal" id="contactForm" name="contact" method="POST" data-netlify="true">
  ب. في script.js احذف الجزء رقم ⑩ (نموذج التواصل) بالكامل.
  ج. أعد رفع المجلد. ستجد الرسائل في Netlify ← Forms.
  د. عدّل جملة «هذا الموقع لا يحتفظ بالرسائل...» أسفل النموذج لتناسب الوضع الجديد.
